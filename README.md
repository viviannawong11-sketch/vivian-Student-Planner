# Student Planner

A responsive study task planner built with HTML, CSS and JavaScript for the ATU Virtual Internship Software Development Mini Project.

## Features
- Add a task with a title and subject or course (blank titles are rejected)
- Pending and Completed sections
- Mark complete / change back to incomplete
- Delete tasks
- Tasks saved with Local Storage (survive refresh)
- Statistics cards: Total, Completed, Pending
- Helpful empty-list messages
- Blue and gold dashboard, responsive for laptops, tablets and phones
- About page with purpose, features and developer info

## Run locally
Open `index.html` in a browser (or use the Live Server extension in VS Code).

## Deploy
1. Push the folder to a GitHub repository.
2. Enable GitHub Pages (Settings > Pages), or drag the folder into Netlify.

## Files
- `index.html` structure
- `style.css` design
- `script.js` functionality
